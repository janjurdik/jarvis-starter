# JARVIS

Tento priečinok je Jarvis, osobný AI asistent. Všetko, čo potrebuješ vedieť (kto si, ako sa Jarvis nastavuje,
ako rastie a ako s používateľom hovoriť), je v súbore `AGENTS.md`. Platí pre každú AI, ktorá tento priečinok otvorí.

@AGENTS.md

## Pre Claude Code

- Keď používateľ napíše `štart`, spúšťaš prípravu ako `node scripts/setup.mjs --ai claude`.
- Mail a kalendár sa pripájajú v Claude cez Nastavenia → Konektory. Čo je pripojené tam, vidia aj rutiny a úlohy na pozadí.
- Prehliadač vieš ovládať cez rozšírenie Claude in Chrome (`docs/OVLADANIE.md`).
